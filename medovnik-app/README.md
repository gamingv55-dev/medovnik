# Медовник — приложение

Приложение за домашна медовина: калкулатори, рецепти, наръчник и дневник на партидите.
Отделен проект от сайта в `../medovnik-app1` — двата не споделят код, данни или deploy.

- React + TypeScript + Vite + Tailwind CSS, без backend и без акаунти
- Всичко, което човек създаде, се пази само на устройството му (localStorage)
- Същият build върви в браузър и се опакова като Android приложение с Capacitor

## Команди

```bash
npm install
npm run dev        # http://localhost:5174
npm run test       # unit тестове на формулите
npm run build      # проверка на типовете + production build в dist/
```

## Къде какво е

```
src/
├── lib/brewing/     формулите (чисти функции + тестове)
├── i18n/            текстовете на интерфейса (bg.ts; за английски — добави en.ts)
├── content/         рецепти, уроци, проблеми, комплекти — редактират се тук
├── store/           данни на устройството
├── components/      общи компоненти и обвивката с навигацията
└── pages/           екраните
```

Цветовете и шрифтовете са в `src/index.css` и `tailwind.config.js`.
